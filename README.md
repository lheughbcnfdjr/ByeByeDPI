# Исследование сетевого стека Android 14 и нагрузочное тестирование фрагментации пакетов (ByeByeDPI)

🎯 Цель исследования и актуальность (Ноябрь 2026)
В условиях усложнения алгоритмов глубокой инспекции пакетов (DPI) стандартные короткие конфигурации фрагментации теряют эффективность. Системы фильтрации научились быстро анализировать первые мегабайты сессии и сбрасывать соединение при обнаружении типовых паттернов.

Основная гипотеза: Использование индивидуальных, сильно удлиненных конфигураций (от +100% до +200% к базовой длине) с множеством микро-задержек (`-d`) и дроблений (`-s`) создает критическую энтропию для анализаторов трафика. При этом нагрузка переносится на центральный процессор (CPU) клиентского устройства.

В ходе тестов проверялся предел вычислительной мощности бюджетных и среднебюджетных ТВ-приставок при воспроизведении потокового видео высокого разрешения (1920x1080 @ 50Hz / 60Hz).

---

📱 Тестовый стенд и совместимое оборудование.
Базовые конфигурации проверены на следующем оборудовании:
* Tanix TX5 — процессор Amlogic S905Y5, ОС Android 14, подключение LAN 100 Мбит/с, Wi-Fi 2.4 ГГц/5 ГГц.
  Выдержала нагрузку вплоть до +200% без пропуска кадров после инициализации потока.
* Vontar X5 — процессор Amlogic S905X5M, ОС Android 14, подключение LAN 100 Мбит/с, Wi-Fi 2.4 ГГц / 5 ГГц. (Рекомендуемая платформа с повышенным запасом производительности).

* Примечание: Конфигурации также применимы для любых других ТВ-приставок, смартфонов и планшетов на базе Android 14 и выше (по LAN или сети Wi-Fi 2.4 / 5 ГГц) с установленным оригинальным клиентом ByeByeDPI (не путать с форком ByeDPIAndroid).

🤖 Инструкция: Как создать свой уникальный конфиг с помощью ИИ.
Главное достоинство данного метода — отсутствие единого шаблона. Вместо копирования готовых длинных строк рекомендуется сгенерировать собственную уникальную цепочку, адаптированную под мощность вашего устройства.
1. Выберите любую базовую конфигурацию из списка ниже.
2. Откройте любой современный ИИ-ассистент (Google Gemini, ChatGPT, Гига-Чат, Claude и др.).
3. Укажите ему параметры вашего устройства: модель приставки/планшета/смартфона, марку процессора и версию Android.
4. Поставьте ИИ задачу: «Проанализируй логику и структуру этой настройки для оригинального приложения ByeByeDPI. На её основе создай 3 новых уникальных варианта, увеличив ДЛИНУ цепочки флагов на любой % (укажите ВАШ ЖЕЛАЕМЫЙ % увеличения длины конфига от +100%....+200%, но НЕ менее +100%), сохраняя синтаксис и баланс задержек под мощность моего процессора».
5. Скопируйте полученную строку и вставьте её в настройки командной строки приложения ByeByeDPI (для удобства на ТВ-приставках рекомендуется использовать USB-клавиатуру, мышь, и буфер обмена).
6. Запустите видеосервис и проверьте стабильность потокового видео через встроенную «Статистику для сисадминов» в нижней части настроек (контролируйте показатели "Connection Speed", "Buffer Health" и "Dropped Frames").
7. Подождите 15...30 секунд для стабилизации процесса.
